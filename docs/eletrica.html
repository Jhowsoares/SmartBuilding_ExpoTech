Engenharia Elétrica

Camada física do Smart Building: sensores, microcontroladores, comunicação sem fio e base para automação do ar-condicionado no laboratório de elétrica.

Arquitetura elétrica

Sensor (DHT/NTC) → Arduino Uno → Bluetooth HC-05 → bt_bridge.py
                                                          ↓
                                                    MQTT Mosquitto
                                                          ↓
                                                    Backend FastAPI

Alternativa: ESP32 + BME280 + PIR → Wi-Fi/MQTT direto (firmware no repositório)

Componentes e integração

ComponenteFunção
Sensor de temperatura / umidadeTelemetria para regras RN01–RN03
Arduino Uno + HC-05Leitura e envio via Bluetooth
ESP32 (opcional)MQTT nativo + controle IR do AC
Eletrodutos aparentesOrganização de cabos (ver maquete Civil)

Formato serial esperado: TEMP:24.5 · PRES:1 · HUM:65.2

No repositório

  • tools/bt_bridge.py — ponte Bluetooth → MQTT
  • firmware/esp32_smartbuilding/ — firmware ESP32
  • Tópicos MQTT — sensors/room/{id}/temperature
  • Hardware ESP32 — pinagem e calibração

Integração multidisciplinar

  • Civil: maquete com passagens para cabos — ver entregas Civil (inclui vista 3D)
  • Produção: sensores e módulos entram no CAPEX — análise financeira
  • Computação: consome telemetria MQTT e envia comandos REST/MQTT
