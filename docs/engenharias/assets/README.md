# Assets — Engenharias

Coloque aqui imagens para exibição no GitHub Pages (pasta pública).

Sugestão de nomes para a página da Civil:

| Arquivo | Conteúdo |
|---------|----------|
| `maquete-3d.jpg` ou `.png` | Render / foto do modelo 3D do laboratório |
| `maquete-fisica.jpg` | Foto da maquete física |
| `infraestrutura.jpg` | Detalhe de isolamento / eletroduto |

Após adicionar os arquivos, elas aparecem automaticamente em `civil.html`.
