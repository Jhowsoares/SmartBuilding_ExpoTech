## Sobre o Projeto

Sistema de monitoramento e automação focado na eficiência energética e controle inteligente de climatização. O ecossistema integra microcontroladores via protocolo MQTT, uma API robusta em FastAPI, persistência de dados e um painel de controle interativo.
